# Computational Structural Biology Portfolio Template

A minimal, research-focused personal website template for showcasing work in computational structural biology, with emphasis on allosteric network prediction from structural dynamical data.

## Files
- `/home/runner/work/website/website/index.html` — main site content and section structure
- `/home/runner/work/website/website/styles.css` — minimal visual style

## Customize
Replace all bracketed placeholders (for example `[Your Name]`, `[Placeholder]`, and profile links) with your own details.
